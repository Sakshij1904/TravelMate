# TravelMate 

TravelMate is a Trip Planner with Budget Calculator developed using Python, Django and MongoDB.

## Features

- User Registration and Login
- Secure Login Authentication
- Create Trip
- View Saved Trips
- Edit Trip
- Delete Trip
- Budget Calculator
- Remaining Budget Calculation
- Budget Status (Within Budget / Budget Exceeded)
- About Us Page

## Technologies Used

- Python
- Django
- MongoDB
- HTML
- CSS

## Project Description

TravelMate helps users plan budget-friendly trips by calculating hotel, food and transport expenses. It allows users to create, view, edit and delete trips while managing their travel budget.

## How to Run

### Step 1: Clone the Repository

bash
git clone <repository-url>


### Step 2: Open the Project Folder

bash
cd travelmate


### Step 3: Install Required Packages

bash
pip install django pymongo


### Step 4: Start MongoDB

Make sure MongoDB is running before starting the project.

### Step 5: Run the Django Server

bash
python manage.py runserver


### Step 6: Open the Project

Open your browser and visit:


http://127.0.0.1:8000/
